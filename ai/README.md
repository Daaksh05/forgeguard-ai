# AI Subsystem - ForgeGuard AI Core

## Purpose
This directory contains the AI core modules that power ForgeGuard's predictive maintenance intelligence.

## Modules Overview
- [vision/](file:///Users/daakshayani/Desktop/ForgeGuard%20AI/ai/vision/README.md): Computer vision models for visual defect and surface anomaly detection.
- [anomaly_detection/](file:///Users/daakshayani/Desktop/ForgeGuard%20AI/ai/anomaly_detection/README.md): Time-series and tabular sensor anomaly detection (vibration, temperature, pressure, etc.).
- [rag/](file:///Users/daakshayani/Desktop/ForgeGuard%20AI/ai/rag/README.md): Document ingestion, indexing, and semantic retrieval over industrial maintenance manuals.
- [agent/](file:///Users/daakshayani/Desktop/ForgeGuard%20AI/ai/agent/README.md): Multimodal orchestration agent correlating evidence to explain faults and recommend operator actions.
