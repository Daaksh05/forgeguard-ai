# Vision Module - Visual Defect Detection

## Purpose
Computer vision models and inference pipelines dedicated to detecting visual anomalies, component wear, and surface defects from industrial camera/video feeds.

## Planned Capabilities
- **Visual Defect Detection:** Identification of cracks, corrosion, misalignment, leakages, and thermal anomalies.
- **Inference Pipeline:** Processing image/video frames and generating structured visual evidence for the reasoning agent.
- **AMD/ROCm Acceleration Target:** Running vision model inference on AMD GPU hardware via ROCm.

*Planned — No vision models or inference scripts created yet.*
