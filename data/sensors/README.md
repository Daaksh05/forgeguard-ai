# Sensor Data

## Purpose
This directory will store representative and benchmark machine sensor datasets (CSV, JSON, Parquet, or time-series dumps).

## Data Streams Covered
- Vibration metrics (accelerometer readings, peak velocity, harmonics)
- Temperature profiles (bearing, motor housing, coolant)
- Pressure & flow rates
- Electrical signals (current draw, voltage spikes)
- Rotational speed (RPM)
